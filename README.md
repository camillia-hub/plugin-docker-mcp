# Docker MCP

Operates the Docker daemon. This plugin installs and configures it in your workspaces.

Upstream server docs: https://www.npmjs.com/package/docker-mcp

Installs from the Camillia hub as `docker-mcp-ce955c`. On every new task the plugin posts
the ready-to-paste `mcp.servers` entry and the setup steps as a task comment.
